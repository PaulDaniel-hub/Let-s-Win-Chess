# Chess Mentor

Chess Mentor is an interactive chess practice and analysis web app designed to help players analyze positions, explore candidate moves, and improve their game.

## Features

- Interactive chessboard
- Legal move validation
- Stockfish engine analysis
- Candidate moves and evaluations
- Move history
- Undo and reset controls
- Edit board and position setup
- Play as White or Black
- Offline practice mode
- Dark, professional interface

Chess Mentor is intended for learning, puzzles, practice, and post-game analysis.
